<골드무한 테스트용 설정방법>
-VS Code 실행
-위쪽 메뉴에서 파일 → 폴더 열기
-현재 프로젝트 폴더 선택(project 3)
예: C:\Users\user\Desktop\game\project 3
-왼쪽 파일 목록에서 index.html을 한 번 클릭
-Ctrl + F를 누르고 아래 문장 검색
const TEST_MODE_UNLIMITED_GOLD




const TEST_MODE_UNLIMITED_GOLD = true;
이면 테스트모드

const TEST_MODE_UNLIMITED_GOLD = false;
이면 게임모드
